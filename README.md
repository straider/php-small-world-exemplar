PHP Small World Exemplar
========================

This Git repository aims to show what needs to be done, and why, to containerise a PHP application - simple "Hello, World!" - using Docker Compose.

It also aims at showing what a simple GitHub Actions Workflow, that builds a container image and deploys it to multiple environments in OpenShift can look like.

There's a branch for each variant:
- Using Apache HTTP Server
- Using NGINX with PHP FPM
- Slightly bigger small world, with MySQL and phpMyAdmin
